글을 쓰는 데 필요한 건 `content/posts/` 안에 마크다운 파일 하나를 만드는 것뿐이다.
파일 이름이 그대로 주소가 된다 — 이 글은 `hello.md` 라서 `/blog/hello/` 에 있다.

## 프런트매터

파일 맨 위 `---` 사이가 메타데이터다.

| 키 | 필수 | 설명 |
| --- | --- | --- |
| `title` | ✔ | 글 제목 |
| `date` | ✔ | `YYYY-MM-DD`. 목록 정렬 기준 |
| `summary` | | 목록과 검색 결과에 뜨는 한 줄 |
| `tags` | | 태그 목록. `/tags/<태그>/` 페이지가 자동으로 생긴다 |
| `draft` | | `true` 면 개발 서버에서만 보이고 배포에서 빠진다 |

`date` 가 없으면 빌드가 실패한다. 조용히 오늘 날짜로 때우는 것보다 낫다.

## 코드

코드 블록은 빌드할 때 [shiki](https://shiki.style) 로 색을 입힌다. 브라우저가
받는 건 이미 칠해진 HTML이라, 하이라이팅 때문에 로드되는 자바스크립트는 없다.

```ts
export function formatDate(iso: string): string {
  const [y, m, d] = iso.split("-");
  return `${y}년 ${Number(m)}월 ${Number(d)}일`;
}
```

라이트/다크 두 벌을 CSS 변수로 같이 실어두고 `prefers-color-scheme` 으로
고른다. 그래서 테마 토글에도 깜빡임이 없다 — 애초에 토글이 없으니까.

## 그 외

> 인용문은 이렇게 나온다.

- 목록
- 도 물론
- 된다

바깥으로 나가는 링크는 자동으로 새 탭에서 열리고, 제목마다 앵커가 붙어서
`#프런트매터` 같은 주소로 바로 걸 수 있다.
