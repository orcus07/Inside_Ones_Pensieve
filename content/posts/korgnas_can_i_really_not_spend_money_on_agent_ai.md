# Agent AI에 돈 안쓰고 배길까?

### Manus와 Openclaw에 몇십만원 녹인 생생 후기

요즘 진짜 뭐가 일어나나 보다라고 “체감” 된다. 이건 나를 빼고 모두가 어디론가 전력질주할 것 같아서 느끼는 FOMO도 아니고, 지난 주부터 업계에서 엄청 도는 “Something Big is Happening” 포스트 때문도 아니다. ~~(참고로 아래 글은 GPT 5.3 Codex 출시 후 AI가 직무를 대체하는 속도가 미친 듯이 빨라지고 있다는 내용으로, 요즘 기술 업계의 변화 속도를 잘 표현해서 읽어보면 좋다.)~~ 변화를 느낀 이유는 지극히 개인적인 이유고 단순한데, 기존 AI 구독료 대비, Agent AI에 지출하는 돈이 10배가 되었기 때문이다. 💸

레터 소개에서 언급했듯 공대 출신이지만 “이과 부적응자”이기 때문에, 나는 비기술자로 정의할 수 있고, 아마 거의 모든 영역에서 안티-트렌디 하다. 소비자 마케팅이나 프로모션을 업으로 삼지도 않아, 마이크로 트렌드 추적에도 바로바로 눈이 가지도 않는다. ChatGPT가 처음 나왔을 때도, 처음 몇 번 써보다가 시큰둥해져서 그만 뒀었다. ~~( 예나 지금이나 나랑 묻고 나랑 답하는 게 더 좋지, 생면 부지의 AI에게 이것저것 말하는 게 어색하다. )~~ 아마 반도체 업계 B2B의 그늘에서 매크로 트렌드를 관망하는데 익숙해서인 것 같다. 당시 내겐 초기 AI 기능이 일반적이지 않은 정보와 맥락을 다루고 필요로 하는 반도체 업에는 별로 도움이 안됐던 것 같다. 딥리서치 기능 정도만 필요할 때 구독해서 활용했었다.

그랬는데, 어느 날 BZCF 이벤트로 나온 [Manus AI](https://news.hada.io/topic?id=19632) ~~(멀티 AI Agent 서비스로 메타가 +$2B에 인수했다.)~~ 에 카드뉴스 생성을 한번 시켜보고, 바로 10만원이 순삭됐다. 🤦‍♂️ 결정적으로 돈을 쓰게 된 이유는 말하면 바로 결과를 제공하기 때문이다. 대충 말했는데도 결과물을 뽑아내고, 한번 결과물을 맛보니깐 완성도를 추구하기 시작하면서, 그때부턴 프롬프트 엔지니어에 빙의해서 미친듯이 Credit을 태웠다. ~~(다만, 내 프롬프트가 이상했는지, 시간이 지나고 다른 일을 시키니깐 튜닝한 결과가 틀어져서 현타 와서 집어치우긴 했다.)~~ 그 때, AI에 대해서 좀 생각이 달라졌던 것 같다. “어 뭐야. 좀 치네?”

그리고 Openclaw가 나오고 설마 하는 호기심에 오래된 노트북에 깔아봤다. 무심코 던진 자연어 한마디에, 1) 폴더 정리를 하는 것과, 2) 초기 AI로 했던 Vibe Coding 프로젝트를 바로 검증/구현/실행하는 걸 보고, 또 눈이 돌았다.😲 Openclaw는 .md 파일로 과거 컨텍스트를 로컬 PC에 저장해놓고 다음 대화에 꺼내는데, 이게 개인화가 되고 맥락에 맞는 맞춤형 답변이 된다. 결정적으로 “장기 기억이 있는 AI”라 만족도가 크다. 그동안 시키고 싶었던 정보 탐색 / 리서치 / 이미지 분석 및 생성을 다 시켜보니, 어느 새 몇 십만원이 순삭됐다. 🤦‍♂️🤦‍♂️ 지금은 여러 모델들을 API로 연결해놓고, 좋아하는 뉴스레터나 유투브 알고리즘 못지않게 들춰보며, 적절히 토큰 관리 한다. ~~(돌아보면 Token 입장료 지출이 좀 컸나 싶기도 하지만, 재밌었다. Token 최적화는 Heartbeat 기능이랑 컨텍스트를 매번 cron 이나 봇이 읽어오지 않게 하자.)~~

여기까지가 내 경험담인데, 그러면 이제 내가 이걸 쓰기 전으로 돌아갈 수 있느냐라고 물으면 아마 아닐 것 같다. Agent AI 서비스가 “어, 말하면 해주네?” 라고 느끼는 순간, 사람들의 행동 패턴이 비가역적으로 변하고, 내가 변화를 느끼기 시작하면 모두가 느낄테니까 말이다. 아마 이런 Tipping Point를 선점하기 위해 Meta가 Manus를 인수했고, OpenAI가 Openclaw 제작자인 Peter Steinberger를 영입했겠지. ~~(사실 코딩하는 기술자들은 GPT 5.3 Codex나 Claude Opus 4.6에서 이미 그런 순간을 느꼈다고들 하고, 이 Openclaw는 비기술자들이 그런 모먼트들을 많이 느낀다고 한다. )~~

시간이 많이 지나고 나면, 올해가 사스포칼립스(SaaS+Apocalypse)와 Agentic AI 시대의 전환점이라 말할 지도 모르겠다. Software를 Per-seat Model 로 구독했던 시대에서, API AI를 Usage/Outcome 기반 과금하는 시대로 변화되는 시대. 클라우드 기반 API 호출 Model은 초기 진입 장벽이 낮고 운영이 쉬워서 금방 비중이 늘어나겠지만, 어느 정도 서비스 복잡도가 커지면 과금 비중이 너무 크게 늘어날테니, 여전히 독립적으로 분리 운영이 필요한 법이나 의료 분야(변호사-의뢰인 or 환자-의사 비밀 유지)에선 On-device 기반 Fine-Tuning Model로 운영이 병행될 것 같다.

다만, 아래 트윗처럼 이제 알고리즘은 여기저기서 그냥 취해오면 되니깐, 진정한 병목이 에너지와 Compute 에 걸린다. 이건 API 호출 또는 Fine-Tuning Model 시나리오 모두 해당된다. 그리고 이 중 추론 Compute의 핵심은 Interconnetion과 Memory Bandwidth라, 여전히 네트워크 회사랑 메모리 공급사는 꾸준하게 중요할 것 같다. 내 일도 아마 높은 확률로 많아지겠다. 주류가 다른 주류로 대체되고 변화하는 걸 보는 건 아직까지 즐겁다.
